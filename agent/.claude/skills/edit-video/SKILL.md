Lessons from real client edits (livestream-style sales clips).

## Selling order

HOOK → intro / context → product → form, colour, texture → try-on or demo → benefits →
size / price / offer → cart CTA as the last line.
Reorder only whole sentences. Keep the original setting, product details and colours.

## Whisper quirks (Vietnamese)

- Word times run slightly early; the code already compensates. Still prefer cuts in clear gaps.
- Whisper drops some fillers (ừm, à, ờ). A "gap" in the transcript may contain a filler; if a cut
  sounds risky, keep a little more.
- It mishears brands, prices and CTAs. Example: "Linh Góc Trám Hình" is really
  "giỏ hàng góc trái màn hình". Fix them with `caption_fixes`.
- Prices: "một trăm tám chín ka" → write the fix as "189K".

## Emphasis

Highlight 1–4 words: the price, the product name, one key number. Never highlight filler words.

## Look

Colour and brightness are applied automatically per niche. Do not mention them in the summary
unless the customer asked.
